### 2. 고급 감성 분석 (sentiment_analysis_advanced.py)

#### 분석 과정

```
원문 → 불용어 제거 → 형태소 분석 → 감성 점수 계산 → 전체 감성 판단
```

#### 기능 상세

**1) 불용어 제거**
```python
stopwords = {
    '의', '가', '이', '은', '들', '는', '좀', '잘', '걍', 
    '과', '도', '를', '으로', '자', '에', '와', '한', '하다',
    # ... 60개 이상의 불용어
}
```

**2) 형태소 분석**
```python
# 정규식 기반 한글 단어 추출 (2글자 이상)
words = re.findall(r'[가-힣]{2,}', text)
```

**3) 감성 사전**

**긍정어 (70개+)**
```python
positive_words = {
    # 주식 관련
    '상승': 2, '급등': 3, '쩜상': 3, '호재': 3,
    '수익': 2, '이익': 2, '배당': 2, '성장': 2,
    
    # 일반 긍정
    '좋다': 1, '최고': 2, '훌륭': 2, '성공': 2,
    '화이팅': 2, '가즈아': 2, ...
}
```

**부정어 (60개+)**
```python
negative_words = {
    # 주식 관련
    '하락': -2, '급락': -3, '쩔하': -3, '악재': -3,
    '손실': -2, '적자': -2, '망했': -3,
    
    # 일반 부정
    '나쁜': -1, '싫': -1, '최악': -3, '실패': -2,
    '조지': -2, '박살': -3, ...
}
```

**4) 감성 판단 로직**
```python
if 긍정_형태소_수 > 부정_형태소_수:
    감성 = '긍정'
elif 부정_형태소_수 > 긍정_형태소_수:
    감성 = '부정'
else:
    if 총점 > 0: 감성 = '긍정'
    elif 총점 < 0: 감성 = '부정'
    else: 감성 = '중립'
```

## 🎯 기술 상세

### 불용어 제거 알고리즘

```python
def remove_stopwords(text):
    """불용어 제거"""
    words = tokenize(text)  # 형태소 분석
    filtered = [word for word in words if word not in stopwords]
    return filtered
```

**제거되는 불용어:**
- 조사: 의, 가, 이, 은, 는, 을, 를, 에, 와, ...
- 대명사: 그, 저, 것, 여기, 거기, 누구, ...
- 접미사: 요, 네, 게, ...

### 형태소 감성 점수

**점수 체계:**
- +3: 매우 긍정 (대박, 쩜상, 급등, 폭등)
- +2: 긍정 (상승, 수익, 이익, 배당, 성장)
- +1: 약간 긍정 (좋다, 믿다, 희망)
- 0: 중립
- -1: 약간 부정 (나쁜, 싫다, 걱정)
- -2: 부정 (하락, 손실, 적자, 매도)
- -3: 매우 부정 (급락, 폭락, 쩔하, 망했다)

### 신뢰도 계산

```python
confidence = (긍정_형태소_수 + 부정_형태소_수) / 전체_형태소_수
```

**신뢰도 해석:**
- 0.8 이상: 매우 높음 (강한 감성 표현)
- 0.5~0.8: 높음 (분명한 감성)
- 0.3~0.5: 보통 (일부 감성 표현)
- 0.3 미만: 낮음 (객관적 서술)
