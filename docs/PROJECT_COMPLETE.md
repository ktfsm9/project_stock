## 🎓 해결한 모든 문제

### 문제 1: KoNLPy 오류 ✅
- **증상:** Okt 로드 실패, 0개 토큰
- **해결:** 정규표현식 기반 토큰 추출
- **파일:** text_analysis_fixed.py

### 문제 2: pykrx API 오류 ✅
- **증상:** JSONDecodeError
- **해결:** yfinance로 전환
- **파일:** data_collection_ratelimit.py

### 문제 3: yfinance Rate Limit ✅
- **증상:** Too Many Requests
- **해결:** 재시도 로직 + 샘플 데이터
- **파일:** data_collection_ratelimit.py

### 문제 4: 파일명 불일치 ✅
- **증상:** kodex200_full_features.csv 없음
- **해결:** 자동 매칭 스크립트
- **파일:** fix_filenames.py

### 문제 5: 백테스팅 엔진 오류 ✅
- **증상:** 'Returns' 컬럼 없음
- **해결:** 간단한 백테스팅 엔진
- **파일:** backtesting_simple.py

### 문제 6: RAG 챗봇 오류 ✅
- **증상:** No columns to parse
- **해결:** 규칙 기반 챗봇
- **파일:** rag_chatbot_simple.py

### 문제 7: 유니코드 로깅 오류 ✅
- **증상:** cp949 인코딩 오류
- **해결:** 이모지 제거
- **파일:** run_pipeline.py
