# 파이프라인 검증 체크리스트 (토론 재크롤링 진행 중)

토론 게시판 데이터를 3개월치로 다시 수집하는 동안, 나머지 단계(3~7)가 프로젝트 주제에 맞게 실행되는지 점검하기 위한 체크리스트입니다.

## 1) 데이터 수집/특징 생성 (3단계)
- [ ] `yfinance` 등 외부 의존성 설치 확인
- [ ] 샘플 데이터 fallback 발생 여부 확인
- [ ] 지표 컬럼에 **주지표/보조지표/거시변수**가 모두 포함되는지 확인

## 2) 상관관계 분석 (4단계)
- [ ] 과도한 상관(예: 이동평균과 동일 구성 지표) 제거 규칙 적용
- [ ] 타깃 누수 가능 컬럼(미래 종가 기반 변환값) 제외 확인

## 3) 백테스팅 (5단계)
- [ ] 전략 성과를 **전체/분기별/연간** 단위로 각각 산출
- [ ] 거래비용, 슬리피지, 체결 지연 등 현실 제약 반영
- [ ] 승률·MDD·샤프를 동일 기간 기준으로 비교

## 4) 머신러닝 (6단계)
- [ ] 시계열 분할(Train < Test) 유지 확인
- [ ] R² 과대(0.999+) 시 누수 점검(look-ahead, target leakage)
- [ ] 방향성 정확도 계산 누락 모델(Voting/Stacking) 보완

## 5) 리포팅/RAG (7단계)
- [ ] fallback 발생 단계는 성공과 분리해 표시 (`SUCCESS_WITH_FALLBACK`)
- [ ] 최종 요약에 데이터 소스 품질 플래그 포함
- [ ] 분기별/연간 성과 테이블을 RAG 컨텍스트에 반영

## 자동 점검 도구
아래 스크립트로 실행 로그를 빠르게 점검할 수 있습니다.

```bash
python tools/validate_pipeline_log.py <log_file.txt>
```
